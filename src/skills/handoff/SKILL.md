name: handoff
description: Write the ekko handoff before a /clear, when you pick the moment -- the same ask ctx's Stop hook makes past the context threshold.
disable-model-invocation: true
---

Write the handoff now, so that /clear loses nothing:
- If this folder has an ekko board, first write as a decision, gotcha or procedure anything later sessions must keep (a constraint, a lesson, a settled choice), so that the handoff carries only the state and the next step. Then write a handoff (kind handoff) on the task in progress: where you stopped, what was decided and why, the files, the notes the next session must read in full, by id (it reads the rest concise, if at all), and the next step as an action the next session takes at once, without exploring first.
- Then end with one line telling the user the handoff is written and that /clear starts a fresh session from it.
- With no board, tell the user in one line why and that /clear starts fresh.
